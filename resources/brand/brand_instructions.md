# Sankalit Document Branding Instructions

Always follow these visual style rules when generating documents:

## 1. Typography
- Use `Calibri` font family universally for all body text, headings, headers, footers, and table elements.
- Use `Consolas` (monospace) for document numbers, file paths, version strings, and technical codes only.
- Heading 1 size must be `14pt` and bold.
- Heading 2 size must be `12pt` and bold.
- Body paragraphs must use regular `Calibri` of size `11pt`.
- Table header text must be `Calibri` Bold, minimum `10pt`, white on Charcoal fill.
- Table body text must be `Calibri` Regular, `11pt` preferred, minimum `10pt` (Rev-04 raised the floor from 9pt to 10pt) — never smaller.
- Figure/table captions must be `Calibri` Italic, `9pt`, Charcoal — never bold.
- Line spacing must be set to `1.15x`.

## 2. Page Layout
- Set top margin to `25.0mm` and bottom margin to `20.0mm`.
- Left and right margins must be set to `25mm` (for Technical Reports / Proposals).

## 3. Brand Colors
- Primary Brand Accent Color: `#F5A623` (Sankalit Orange) for rule lines, borders, and fills — never on heading text.
- Secondary Brand Highlight Color: `#F7C05A` (Sankalit Amber) for highlights and summary sub-fills.
- All heading text (H1-H4) must use Charcoal (`#5A5A5A`). Body text, H3/H4 headings, and table body text use Dark Grey (`#333333`). Never use pure black for text.

## 4. Company Name
- Always write the company name as `Sankalit Consultant`. Never `Sankalit IT Consultant`, and never append `Pvt. Ltd.` or pluralize to `Consultants`.
